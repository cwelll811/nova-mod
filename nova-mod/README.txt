BUDOWANIE PRZEZ GITHUB (bez instalowania Javy)
1. Zaloz konto na github.com i kliknij New repository (np. "nova-mod", Public).
2. Na stronie repo: "uploading an existing file" i przeciagnij CALA zawartosc rozpakowanego folderu
   (razem z folderem .github - jest ukryty, wlacz pokazywanie ukrytych plikow).
   Kliknij Commit changes.
3. Zakladka Actions -> poczekaj ok. 3-5 min na zielony ptaszek.
4. Wejdz w ukonczony przebieg -> na dole "Artifacts" -> nova-jar (pobierze sie zip z nova-1.0.0.jar).
5. Wrzuc nova-1.0.0.jar + Fabric API 1.21.4 do .minecraft/mods.

UZYCIE: Prawy Shift = ClickGUI.
